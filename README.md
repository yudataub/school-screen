# מסך בית הספר – התוכן

המסך עצמו: https://www.kol-toda.co.il/screen/
כאן נמצא רק התוכן: `config.json` (שקופיות ושעות הפסקה) ותיקיית `images` (תמונות).
עורכים ישר כאן, באתר GitHub. השינוי מופיע במסך תוך כמה דקות, בלי לגעת בטלוויזיה.

## להוסיף תמונה
1. נכנסים לתיקייה `images` ← Add file ← Upload files, ומעלים (שם באנגלית, בלי רווחים, למשל `tiyul-1.jpg`) ← Commit changes.
2. פותחים את `config.json` ← סמל העיפרון, ומוסיפים שורה ברשימת השקופיות:
   `{ "type": "image", "src": "images/tiyul-1.jpg" }`
3. תמונה עם כיתוב: `{ "type": "image-text", "src": "images/tiyul-1.jpg", "title": "טיול שנתי", "body": "כיתה ד' בגליל" }`
4. שקופית טקסט: `{ "type": "text", "title": "כותרת", "body": "טקסט" }`. ירידת שורה בתוך הטקסט כותבים `\n`.
5. שקופית שצריכה יותר זמן: מוסיפים `"seconds": 20`.
6. Commit changes.

בין שורה לשורה יש פסיק. אחרי השורה האחרונה ברשימה אין פסיק.
מחליפים תמונה קיימת? נותנים לקובץ החדש שם חדש, אחרת המסך עלול להמשיך להציג את הישנה.
התמונה מוצגת בשלמותה ולא נחתכת. הכי יפה: תמונה רוחבית (16:9).

## לשנות שעות הפסקה
ב-`breaks`, לכל הפסקה: `"start": "10:00"` ו-`"end": "10:20"` (שעון 24 שעות, עם נקודתיים).
`days`: ‏0 = ראשון, 1 = שני, 2 = שלישי, 3 = רביעי, 4 = חמישי, 5 = שישי.
מחוץ לשעות ההפסקה מוצגות השקופיות שב-`default`.

## תוך כמה זמן השינוי מופיע
דקה-שתיים עד ש-GitHub מעדכן, ועוד עד `refreshMinutes` דקות (כרגע 5) עד שהמסך טוען מחדש.
אם אין אינטרנט, המסך ממשיך להציג את התוכן האחרון.

## לבדוק ש-config.json תקין
פסיק חסר או מיותר שובר את הקובץ. המסך לא יישבר (הוא ימשיך להציג את הגרסה הקודמת), אבל השינוי לא יופיע.
- העורך של GitHub מסמן שגיאה בקו אדום גלי.
- או להדביק את התוכן ב-https://jsonlint.com לפני השמירה.
